📚 Yori's House — Wiki & Documentation

🏠 Overview

Yori's House is a digital storefront and portfolio organized as an interactive house metaphor. Each "room" represents a different category of creative work — music, art, game assets, software, and more. The site features ambient visuals (starry canvas, film grain, cursor glow), responsive design with desktop/mobile toggles, and smooth micro-interactions.

🗺️ Site Structure

  • Homepage (index.html) — Main landing page with hero section, room previews, music section, about, purchase info, and social links.
  • Room Pages (rooms/*.html) — Dedicated pages for each category:
    • 01-songs.html — Original Songs
    • 02-illustration.html — Illustration & Anime Art
    • 03-game-assets.html — Game Assets
    • 04-yori-os.html — Yori OS (Software)
    • 05-everything-else.html — Everything Else
  • Assets
    • assets/css/main.css — All styles
    • assets/js/view-detect.js — Viewport detection logic
    • assets/js/home.js — Homepage interactions
    • assets/js/site.js — Room page interactions
    • assets/js/copy-usdt.js — Copy-to-clipboard utility
    • assets/img/ — Images (yori_hero.jpg, etc.)

✨ Key Features

Visual Design

  • Animated starfield canvas background
  • Film grain overlay for texture
  • Dynamic cursor glow effect
  • Responsive typography (Fraunces + Space Grotesk)
  • Dark theme with accent colors per room

Interactions

  • Desktop/Mobile layout toggle (dev tool)
  • Hover-activated room lighting effects
  • Smooth scroll navigation
  • Collapsible mobile menu
  • Toast notifications for actions
  • USDT address copy-to-clipboard

Accessibility

  • Semantic HTML structure
  • ARIA labels on interactive elements
  • Keyboard navigation support
  • High contrast text

💰 Purchase Flow

To purchase access or items from Yori's House:

  1. Navigate to the "Buy" section (#buy)
  2. Review the pricing tiers and offerings
  3. Click the USDT address to copy it to clipboard
  4. Send payment via your crypto wallet
  5. Contact via Discord with proof of payment
  6. Receive access codes or download links

Supported Currency: USDT (TRC20 or ERC20)

🔧 Technical Details

Technologies Used

  • HTML5 — Semantic markup
  • CSS3 — Custom properties, flexbox/grid, animations
  • Vanilla JavaScript — No frameworks, modular architecture
  • Canvas API — Starfield animation
  • Google Fonts — Fraunces (serif) + Space Grotesk (sans)
  • Fontsource — Self-hosted font delivery via CDN

Browser Support

  • Chrome/Edge (latest)
  • Firefox (latest)
  • Safari (latest)
  • Mobile Safari & Chrome

Performance Optimizations

  • Preconnect to font CDN
  • Deferred script loading
  • CSS containment where applicable
  • Minimal DOM manipulation
  • No external JavaScript dependencies

📱 Responsive Behavior

The site adapts to different screen sizes:

  • Desktop (>= 1024px) — Full navigation bar, multi-column layouts, hover effects enabled
  • Tablet (768px - 1023px) — Compressed navigation, adjusted grid columns
  • Mobile (< 768px) — Hamburger menu, single-column layouts, touch-optimized interactions

The developer toggle in the navbar allows previewing mobile/desktop layouts regardless of actual viewport size.
